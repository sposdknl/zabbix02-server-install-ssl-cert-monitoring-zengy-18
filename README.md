Dokumentace k Zabbix Serveru - Zabbix web frontend je plně funkční, protože všechny klíčové služby běží a jsou aktivní: Apache2 poskytuje webový server, MySQL/MariaDB je spuštěná a přijímá připojení, a Zabbix server je aktivní a připraven zpracovávat data. Databáze zabbix byla vytvořena, obsahuje všechny potřebné tabulky včetně dbversion a byla naimportována pomocí SQL skriptů z instalace Zabbixu, přičemž byl při tom zajištěn správný stav práv a kompatibilita s MySQL 8 (např. nastavením log_bin_trust_function_creators = 1). Uživatelský účet zabbix má správně nastavené heslo, které odpovídá hodnotě v souboru zabbix.conf.php, a má plná oprávnění nad databází, takže frontend může bez problémů číst a zapisovat data. PHP má nainstalovaný modul php-mysql, což umožňuje spojení mezi webem a databází. Frontend je dostupný na http://127.0.0.1:8080/zabbix, připojení lze ověřit příkazem mysql -u zabbix -p -h localhost zabbix a funkčnost databáze potvrzuje přítomnost tabulek jako dbversion přes USE zabbix; SHOW TABLES LIKE 'dbversion';, což zaručuje, že Zabbix frontend je připraven k používání ale vyhazuje mi chybu „Cannot connect to the database. Unable to select configuration.“.
